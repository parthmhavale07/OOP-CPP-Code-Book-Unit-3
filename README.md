## 💻 Programs

This repository contains **16 practical programs** based on Polymorphism concepts in C++. The programs cover compile-time polymorphism, operator overloading, run-time polymorphism, virtual functions, abstract classes, and real-world applications.

### 01. Function Overloading

Demonstrates compile-time polymorphism using multiple functions with the same name but different parameter lists.

### 02. Area Calculator

Demonstrates function overloading to calculate the area of different shapes using different parameters.

### 03. Unary Minus Operator

Demonstrates unary operator overloading using the unary minus operator.

### 04. Prefix and Postfix Increment

Demonstrates overloading of prefix and postfix increment operators.

### 05. Complex Number Addition

Demonstrates binary `+` operator overloading to add two complex numbers.

### 06. Relational Operator Overloading

Demonstrates overloading of the `>` operator to compare two user-defined objects.

### 07. Friend / Non-Member Operator

Demonstrates operator overloading using a friend non-member function.

### 08. Base Pointer Without Virtual Function

Demonstrates static binding using a base-class pointer without a virtual function.

### 09. Base Pointer With Virtual Function

Demonstrates run-time polymorphism using a virtual function and base-class pointer.

### 10. Base Reference With Virtual Function

Demonstrates dynamic binding through a base-class reference and virtual function.

### 11. Abstract Class and Pure Virtual Function

Demonstrates the use of an abstract class and pure virtual function.

### 12. Collection of Polymorphic Shape Pointers

Demonstrates processing different derived objects through a common abstract base interface.

### 13. Virtual Destructor

Demonstrates safe destruction of derived objects through a base-class pointer.

### 14. Object Slicing

Demonstrates object slicing and shows how references can preserve the complete derived object.

### 15. Payment Processing System

Demonstrates a real-world payment system using abstract classes and run-time polymorphism.

### 16. Employee Payroll Mini-Project

Demonstrates an integrated payroll application using abstract classes and run-time polymorphism.
